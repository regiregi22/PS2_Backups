# PS2_Backups
Instrucciones para crear una Memory Card que permita cargar copias de seguridad por USB en la Playstation 2.

1.- Instroducir en zocalo MC-0 una memory card que tengas ya con FMCB/wLaunchELF. Introducir en MC-1 la tarjeta que queramos crear (AVISO: se borrarán todos los datos que haya).

2-. Ejecutar desde MC0 el "wLaunchELF". Navegar hasta "usb:/MCA/mca_new/", ejecutar "mca.elf". Elegimos "slot 2" (la MC-1), "Format Full", elegimos "8Mb" y "Yes".
